# Test environment for the Phoenix MCP integration tests (pytest).

# pytest-homeassistant-custom-component (PHACC) is the single source of truth for
# the Home Assistant test stack: each PHACC version pins an exact homeassistant
# version plus the matched pytest, pytest-asyncio, aiohttp, sqlalchemy, etc. So
# pinning PHACC pins the primary test stack; deeper transitive packages can
# still float within the ranges their dependents allow.
#
#   PHACC 0.13.371 pins homeassistant==2026.10.0.
#   Python: 3.14
#
# This is a TEST pin only. hacs.json and const.MIN_HA_VERSION declare the
# supported runtime floor, tested separately in CI. Keep this stack tracking
# the live HA version and rerun the suite on every upgrade; ws_dispatch uses
# version-sensitive Home Assistant APIs.
#
# Set up / upgrade:
#   python3.14 -m venv venv
#   venv/bin/python -m pip install -r requirements_test.txt
#   # to bump: edit the pins below (or pip install --upgrade the packages,
#   # then pip freeze the two lines back into this file)
#   venv/bin/python -m pytest
