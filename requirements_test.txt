# Test environment for the Phoenix MCP integration tests (pytest).
#
# pytest-homeassistant, Home Assistant's own test package, is the single source of
# truth for the test stack: each release pins the exact homeassistant of the same
# version plus the matched pytest, pytest-asyncio and test helpers. So pinning it
# pins the primary test stack; deeper transitive packages can still float within
# the ranges their dependents allow. It must never be installed together with
# pytest-homeassistant-custom-component.
#
#   pytest-homeassistant 2026.11.0 pins homeassistant==2026.11.0.
#   Python: 3.14.2 or newer
#
# This is a TEST pin only. hacs.json and const.MIN_HA_VERSION declare the
# supported runtime floor, tested separately in CI. Keep this stack tracking
# the live HA version and rerun the suite on every upgrade; ws_dispatch uses
# version-sensitive Home Assistant APIs.
#
# Set up / upgrade:
#   python3.14 -m venv venv
#   venv/bin/python -m pip install -r requirements_test.txt
#   # to bump: edit the pins below, using the matching HA component manifests
#   venv/bin/python -m pytest
