A persona is a starting set of capabilities: which kinds of tools the agent can use, and which ones wait for your approval first.

Phoenix selects {{label:personas.new_user.label}} for you, as a cautious start for a first test. If you already know the agent's job, select another. To change single capabilities later, use [{{label:accessKeys.cardCapabilities}}](guide:window.capabilities).

A persona doesn't decide which devices the agent can reach. You select those two steps from now. The exception is {{label:personas.home_companion.label}}, which only ever reaches household devices.

Related: [What each persona allows](guide:window.persona)
