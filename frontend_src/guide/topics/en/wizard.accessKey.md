---
{ "id": "wizard.accessKey", "title": "Naming the Access Key" }
---
The access key is what the agent presents to Phoenix. Its name appears in the audit log and in approvals, so choose one that says which agent uses it.

An expiry ends the key automatically, and it cannot be changed once the key exists. **{{label:wizard.createAccessKey}}** creates the key; if you connect an external app, its secret value appears on the Connect step.
