---
The agent uses this access key to connect to Phoenix. Its name appears in the audit log and in approvals, so pick a name that says which agent uses it.

Use 3 to 32 letters, digits, underscores or hyphens. Each key needs its own name, so change the suggested one if you've run the wizard before.

An expiry date ends the key automatically, and you can't change it once the key exists. **{{label:wizard.createAccessKey}}** creates the key.

If you're connecting an external app, the key's value appears in the Connect step. With Agent Chat it's never shown; to use the key in an app later, rotate it to get a value.
