---
The agent uses this access key to connect to Phoenix. The key's name appears in the audit log and in approvals, so pick a name that says which agent uses it.

An expiry date ends the key automatically, and you can't change it once the key exists. **{{label:wizard.createAccessKey}}** creates the key. If you're connecting an external app, its secret value appears in the Connect step.
