Phoenix is installed. This wizard sets up your first agent and ends with a test you can see working.

- **{{label:wizard.choiceChatTitle}}** runs the agent in a chat window inside Home Assistant. You bring an API key from a model provider, or the address of a local Ollama server.
- **{{label:wizard.choiceAppTitle}}** connects an MCP app you already use, such as Claude Code or an IDE, with a bearer access key.

Either way the agent gets its own access key, and the next steps decide what that key may do. Set up more agents later with **{{label:accessKeys.setUpAgent}}**.
