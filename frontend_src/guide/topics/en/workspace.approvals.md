Approvals holds the changes agents asked to make through capabilities set to confirm. Nothing runs until you decide.

- **{{label:approvals.tabPending}}** lists the requests waiting for you. Open one to see exactly what would change.
- **{{label:approvals.approve}}** runs the request. **{{label:approvals.reject}}** refuses it, and you can tell the agent why.
- **{{label:approvals.tabHistory}}** keeps the requests already decided.

Configuration that agents change is recorded in [Changes](guide:workspace.changes), where an earlier version can be put back.
