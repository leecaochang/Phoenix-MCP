Logs shows what reached Phoenix and what agents said.

- **{{label:shell.tabAudit}}** records requests to Phoenix with their outcome, access key, method and resource.
- **{{label:conversations.title}}** keeps recorded agent conversations, such as Agent Chat sessions.
- Select a record in either log to read it in full in **{{label:workspace.logDetails}}**.

What is recorded, and for how long, is set in [Settings](guide:workspace.settings).
