我的工作区汇集了你在其他工作区中最常用的窗口。它一开始是空的。

相关：[使用窗口](guide:topic.windows)

## 添加窗口 {#adding}

在窗口菜单中选择 **{{label:workspace.addToMy}}**。窗口仍留在它自己的工作区，两份副本显示同一个已选记录。筛选、列和大小在各副本中相互独立。

第一个窗口会填满工作区。之后每个窗口会按行放在其他窗口旁边或下方。

## 移除窗口 {#removing}

在这里关闭窗口会将其移除。要把它找回来，请从它自己的工作区再次添加。**{{label:workspace.restoreOriginal}}** 会移除所有窗口。

这里的“我的默认布局”会保留布局及其中的窗口，因此还原它会带回你此后移除的窗口。

## {{label:workspace.verticalScrolling}} {#scrolling}

默认关闭，因此窗口共用屏幕高度。可在此处任一窗口的菜单中开启，让工作区变高并可滚动。每个窗口随后会恢复之前的高度。

开启后，拖动窗口下方的边框可把它调高。

## Agent Chat {#chat}

在 Agent Chat 自己的菜单中选择 **{{label:workspace.addToMy}}**，即可将它停靠在这里。显示其他工作区时，Chat 会浮在其上；回到这里时它再次停靠。如果期间你关闭了它，它会保持关闭；它窗口中的 **{{label:shell.agentChat}}** 可将其打开。**{{label:agentchat.floatChat}}** 会取消停靠，在这里关闭则会关闭 Chat。

## 在手机上 {#phones}

在窗口菜单中选择 **{{label:workspace.addToMy}}** 将其添加到这里，在这里关闭即可移除。手机上不能添加 Agent Chat。手机保留自己的“我的工作区”，与电脑上的相互独立。
