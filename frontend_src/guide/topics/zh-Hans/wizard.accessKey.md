---
智能体使用此访问密钥连接到 Phoenix。它的名称会出现在审计日志和审批中，所以请选一个能说明由哪个智能体使用的名称。

使用 3 到 32 个字母、数字、下划线或连字符。每个密钥都需要自己的名称，如果你之前运行过向导，请修改建议的名称。

有效期会自动结束密钥，密钥创建后无法更改。**{{label:wizard.createAccessKey}}** 会创建密钥。

如果你连接的是外部应用，密钥的值会显示在连接步骤中。使用 Agent Chat 时它从不会显示；之后要在应用中使用该密钥，请轮换它以获取一个值。
