统计自上次重置以来 Agent Chat 消息的处理方式：由 Home Assistant 的句子匹配、决策提供商还是你的 AI 模型。使用{{label:settings.agentcliCard}}窗口中的 **{{label:routingStats.show}}** 打开它，或从 **{{label:workspace.options}}** 打开。

即使 **{{label:routing.enableChat}}** 关闭，每条 Agent Chat 消息也会计数。AI 任务和外部应用不计数。

相关：[阅读统计](guide:topic.routingStatistics)、[直接处理聊天命令](guide:window.settingsChat#chat-commands)
