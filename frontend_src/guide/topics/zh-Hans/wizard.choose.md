Phoenix 已安装。本向导会设置你的第一个智能体，并以一个你可以观看的测试结束。

这就是指南。它会解释这里的每一步，之后也会解释你正在处理的内容。如果它挡住你了，可以拖动标题栏或从边缘调整大小。

- **{{label:wizard.choiceChatTitle}}** 在 Home Assistant 内的聊天窗口中运行智能体。你需要来自模型提供商的 API 密钥，或本地 Ollama 服务器的地址。
- **{{label:wizard.choiceAppTitle}}** 用 Bearer 访问密钥连接你已在使用的 MCP 应用，例如 Claude Code 或 IDE。

无论哪种方式，智能体都会获得自己的访问密钥，接下来的步骤决定该密钥能做什么。之后可以用 **{{label:accessKeys.setUpAgent}}** 设置更多智能体。
