---
智慧體會使用此存取金鑰連線到 Phoenix。它的名稱會出現在稽核日誌和核准中，因此請選一個能說明由哪個智慧體使用的名稱。

使用 3 到 32 個字母、數字、底線或連字號。每個金鑰都需要自己的名稱，如果你之前執行過精靈，請修改建議的名稱。

有效期會自動結束金鑰，金鑰建立後無法變更。**{{label:wizard.createAccessKey}}** 會建立金鑰。

如果你連接的是外部應用程式，金鑰的值會顯示在「連線」步驟中。使用 Agent Chat 時它永遠不會顯示；之後若要在應用程式中使用該金鑰，請輪換它以取得新值。
