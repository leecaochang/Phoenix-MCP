統計自上次重設以來 Agent Chat 訊息的處理方式：由 Home Assistant 的句子比對、決策提供者還是你的 AI 模型。使用{{label:settings.agentcliCard}}視窗中的 **{{label:routingStats.show}}** 開啟它，或從 **{{label:workspace.options}}** 開啟。

即使 **{{label:routing.enableChat}}** 關閉，每則 Agent Chat 訊息也會計數。AI 任務和外部應用程式不計數。
