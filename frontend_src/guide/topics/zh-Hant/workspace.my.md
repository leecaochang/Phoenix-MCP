我的工作區會彙整你在其他工作區中最常用的視窗。它一開始是空的。

相關：[使用視窗](guide:topic.windows)

## 新增視窗 {#adding}

在視窗選單中選擇 **{{label:workspace.addToMy}}**。視窗仍會留在它自己的工作區，兩份副本會顯示同一筆所選記錄。篩選、欄和大小在每份副本中各自獨立。

第一個視窗會填滿工作區。之後每個視窗會依序放在其他視窗旁邊或下方，一次一列。

## 移除視窗 {#removing}

在這裡關閉視窗會將它移除。若要把它找回來，請從它自己的工作區再次新增。**{{label:workspace.restoreOriginal}}** 會移除所有視窗。

這裡的「我的預設佈局」會保留佈局及其中的視窗，因此還原它會帶回你之後移除的視窗。

## {{label:workspace.verticalScrolling}} {#scrolling}

預設為關閉，因此視窗會共用螢幕高度。可在此處任一視窗的選單中開啟，讓工作區變高並可捲動。每個視窗之後會恢復先前的高度。

開啟後，拖曳視窗下方的邊框即可將它調高。

## Agent Chat {#chat}

在 Agent Chat 自己的選單中選擇 **{{label:workspace.addToMy}}**，即可將它停駐在這裡。顯示其他工作區時，Chat 會浮在其上；回到這裡時會再次停駐。如果期間你關閉了它，它會保持關閉；它視窗中的 **{{label:shell.agentChat}}** 可以將它開啟。**{{label:agentchat.floatChat}}** 會取消停駐，在這裡關閉則會關閉 Chat。

## 在手機上 {#phones}

在視窗選單中選擇 **{{label:workspace.addToMy}}** 將它新增到這裡，在這裡關閉即可移除。手機上無法新增 Agent Chat。手機保有自己的「我的工作區」，與電腦上的各自獨立。
