Phoenix 已安裝。此精靈會設定你的第一個智慧體，並以一個你可以觀看的測試結束。

這就是指南。它會說明這裡的每一步，之後也會說明你正在處理的內容。如果它擋住你了，可以拖曳標題列或從邊緣調整大小。

- **{{label:wizard.choiceChatTitle}}** 在 Home Assistant 內的聊天視窗中執行智慧體。你需要模型提供者的 API 金鑰，或本機 Ollama 伺服器的位址。
- **{{label:wizard.choiceAppTitle}}** 用持有者存取金鑰連接你已在使用的 MCP 應用程式，例如 Claude Code 或 IDE。

無論哪種方式，智慧體都會取得自己的存取金鑰，接下來的步驟會決定該金鑰可以做什麼。之後可以用 **{{label:accessKeys.setUpAgent}}** 設定更多智慧體。
