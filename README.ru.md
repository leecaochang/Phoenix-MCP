Phoenix MCP даёт вашим ИИ-агентам ограниченный доступ к Home Assistant по принципу минимальных привилегий. Каждый клиент получает собственный ключ доступа, ограниченный ровно теми сущностями, которые вы разрешите, с собственными возможностями, ограничением частоты и необязательным сроком действия. Аудит включён по умолчанию и настраивается по каждому результату, любой ключ доступа можно мгновенно отозвать, а слой семантической безопасности для каждой сущности (MESA) может сделать устройство доступным только с подтверждением или полностью запрещённым по его природе, независимо от выданных ключу доступа разрешений. По умолчанию MESA работает в рекомендательном режиме: большинство ограничений только предупреждают до выбора принудительного режима; свойства только для чтения и явные запреты конфиденциальности продолжают блокировать.

Phoenix MCP полностью работает внутри Home Assistant: без отдельной службы для развёртывания, без облачной зависимости в основном сервере и без настройки, кроме панели Phoenix MCP (необязательные функции «Agent Chat», голос и AI-задача отправляют диалоги настроенному вами провайдеру моделей, если вы не укажете локальный Ollama). Он работает с MCP-клиентами, которые вы уже используете (Claude Code, Cursor, ChatGPT/Codex, Gemini и другие), или можно вовсе не устанавливать клиент и общаться прямо из Home Assistant. В любом случае управляемая настройка за несколько минут проведёт вас от нового ключа доступа к работающему агенту, опираясь на каталог из 174 инструментов для чтения, управления и создания конфигурации. Панель доступна на нескольких языках, по умолчанию следует языку вашего профиля Home Assistant и переключается на английский, когда этот язык недоступен. Home Companion и необязательная маршрутизация решений также могут отправлять запросы и разрешённые результаты размещённому провайдеру. Внешние MCP-клиенты используют собственные настройки провайдера и передачи данных.

## Языки

Сейчас панель поддерживает английский, испанский, французский, итальянский, немецкий, нидерландский, польский, русский, упрощённый китайский, традиционный китайский, корейский, японский, шведский, датский, норвежский и финский. Чтобы изменить язык панели вручную, откройте **Phoenix MCP > Настройки > Язык** и выберите язык. Выберите **Авто**, чтобы снова следовать языку вашего профиля Home Assistant.

## Документация

Справка встроена в панель: откройте панель **Phoenix MCP** и выберите **Руководство** в меню **Документация**. Она объясняет каждое окно и каждую настройку, что могут делать агенты, разрешения, возможности, MESA, безопасность и административный API, а также поддерживает поиск.

Впервые здесь? Откройте панель **Phoenix MCP** и выберите **Настроить агента** в разделе Ключи доступа. Мастер создаёт ваш первый ключ доступа, определяет, что ему разрешено, затем позволяет общаться из Home Assistant или подключить внешнее приложение и завершается тестом, за которым вы можете наблюдать.

## Требования

- Home Assistant 2026.7.0 или новее.
- Один экземпляр Phoenix MCP на Home Assistant. Home Assistant устанавливает зависимости Python `Babel>=2.18.0`, `jsonschema>=4.26.0` с учётом своих ограничений зависимостей; MESA включена в Phoenix MCP.

## Установка из Marketplace

В Home Assistant 2026.11 или новее:

1. Откройте **Настройки > Marketplace** и выберите **Добавить по ссылке**.
2. Введите `https://github.com/leecaochang/Phoenix-MCP` и выберите **Добавить**. При первом добавлении Marketplace попросит подключить GitHub.
3. Откройте Phoenix MCP, выберите **Установить** и перезапустите Home Assistant.

При обновлении с HACS Phoenix MCP сам перейдёт в Marketplace. Подключите там GitHub, чтобы и дальше получать обновления.

## Установка через HACS

В Home Assistant 2026.10 или старше:

1. В HACS откройте меню в правом верхнем углу и выберите **Пользовательские репозитории**.
2. Введите `https://github.com/leecaochang/Phoenix-MCP`, выберите категорию **Интеграция** и нажмите **Добавить**.
3. Найдите Phoenix MCP в списке интеграций HACS, установите его и перезапустите Home Assistant.

Предпочитаете установить вручную? Скопируйте папку `custom_components/phoenix_mcp` в каталог конфигурации Home Assistant в `custom_components/phoenix_mcp`, затем перезапустите.

### Настройка

Перейдите в **Настройки > Устройства и службы > Добавить интеграцию** и найдите **Phoenix MCP**. Пройдите одношаговый поток настройки, затем откройте панель **Phoenix MCP** в боковой панели и выберите **Настроить агента**.
